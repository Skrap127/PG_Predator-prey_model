\chapter[Modelo de Leslie-Gower]{El modelo de Leslie-Gower con respuesta funcional sigmoidea}

En este capítulo se analiza el modelo presa-depredador de tipo Leslie-Gower propuesto por González-Olivares et al. (2015)\cite{articulo}, en el cual la población de presas exhibe una respuesta funcional de Holling tipo III, caracterizada por su forma sigmoidea.

\section{Descripción del modelo}

El modelo se describe mediante el siguiente sistema autónomo de ecuaciones diferenciales ordinarias de tipo Kolmogorov:

\begin{equation}
	X_{\mu} =
	\begin{cases}
		\dfrac{dx}{dt} = \left(r \left(1 - \dfrac{x}{K}\right) - \dfrac{q x y}{x^2 + a^2}\right) x, \\
		\dfrac{dy}{dt} = s \left(1 - \dfrac{y}{n x}\right) y,
	\end{cases}
	\label{eq:modelo1}
\end{equation}

donde $x(t)$ y $y(t)$ representan las densidades poblacionales de presas y depredadores, respectivamente, para $t \geq 0$. Los parámetros $\mu = (r, a, s, K, n, q) \in \R^6_{+}$ son estrictamente positivos y tienen el siguiente significado biológico:

\begin{itemize}
	\item $r$: tasa de crecimiento intrínseco de las presas;
	\item $K$: capacidad de carga ambiental de las presas;
	\item $q$: tasa máxima de consumo per cápita de los depredadores (tasa de saciedad);
	\item $a$: cantidad de presas necesarias para alcanzar la mitad de $q$ (media de la tasa de saturación);
	\item $s$: tasa de crecimiento intrínseco de los depredadores;
	\item $n$: medida de la calidad alimenticia, que indica la eficiencia de conversión de presas consumidas en nuevos depredadores.
\end{itemize}

El sistema \eqref{eq:modelo1} no está definido en $x=0$ (eje $y$), por lo que el dominio biológicamente relevante es el conjunto $\Omega = \{ (x,y) \in \R^2 \mid x > 0, \; y \geq 0 \}$.

\section{Análisis}

Dado un sistema $\dot{X} = f(X)$ con $X = (x,y)$, los puntos críticos se obtienen resolviendo $f(X) = 0$. Para el sistema \eqref{eq:modelo1}, esto es:

\begin{equation}
	\begin{cases}
		\left(r \left(1 - \dfrac{x}{K}\right) - \dfrac{q x y}{x^2 + a^2}\right) x = 0, \\
		s \left(1 - \dfrac{y}{n x}\right) y = 0.
	\end{cases}
	\label{eq:sistema-eq}
\end{equation}

De la segunda ecuación, $y = 0$ o $y = n x$. Para $y=0$, se obtiene $x = K$, por tanto $(K,0)$ es un punto crítico. De las intersecciones de las isoclinas $$y = n x, \; \; \; \; \; \; y = \dfrac{r}{q x} \left(1 - \dfrac{x}{K}\right) (x^2 + a^2),$$

se obtinene los demás puntos críticos del sistema, donde se verificará más adelante que solo existe una solución $(x_e, y_e) \in \R^2$,  el cual existe en el primer cuadrante si y solo si $x_e < K$.

Con el propósito de analizar el comportamiento cualitativo del sistema y simplificar los cálculos algebraicos, introducimos el cambio de variables $x = K u$ y $y = n K v$, la cual define una transformacion lineal y por ende, un difeomorfismo entre el sistema \eqref{eq:modelo1} y el resultante:
\begin{equation*}
	\begin{cases}
		\dfrac{du}{dt} = r\left((1-u) - \dfrac{qn}{r} \dfrac{uv}{u^{2}+\left(\dfrac{a}{K}\right)^{2}}\right)u \\
		\dfrac{dv}{dt} = s \left(1-\dfrac{v}{u}\right)v
	\end{cases}.
\end{equation*}
Posteriormente, se realiza un reescalado de la variable temporal mediante la relación diferencial $d\tau = r/[u(u^2+A^2)]dt $, donde $A = a/K$. Dado que el factor de escala $r/[u(u^2+A^2)]$ es una función suave y positiva en el conjunto de definición $\bar{\Omega} = \{ (u, v) \in \R^{2} \; | \; u > 0, \; v \geq 0 \}$, la dirección de las trayectorias se preserva \cite{chicone2024}[p.~14](Colocar proposicion 1.14 en preli), por lo que el sistema resultante al aplicar el reescalado será topológicamente equivalente, este es:
\begin{equation*}
	\begin{cases}
		\dfrac{du}{d\tau} = \left((1-u)\left(u^{2}+\left(\dfrac{a}{K}\right)^{2}\right) - \dfrac{qn}{r} uv\right)u^{2} \\
		\dfrac{dv}{d\tau} = \dfrac{s}{r} \left(u-v\right)\left(u^{2}+\left(\dfrac{a}{K}\right)^{2}\right)v
	\end{cases}
\end{equation*}
Esto da paso a la siguiente proposición.

\begin{pro}
	El sistema \eqref{eq:modelo1} es topológicamente equivalente al sistema
	\begin{equation}
		Y_{\eta}:
		\begin{cases}
			\dfrac{du}{d \tau} = ((1 - u)(u^{2} + A^{2}) - Q u v)u^{2}\\
			\dfrac{dv}{d \tau} = B(u - v)(u^{2} + A^{2})v
		\end{cases},
		\label{eq: modelo2}
	\end{equation}
	donde, $\eta = (A, Q, B) \in (0, 1) \times \R^{2}_{+}$ con $A = \dfrac{a}{K}, \; Q = \dfrac{qn}{r}, \; B = \dfrac{s}{r}$.
\end{pro}

\begin{proof}
	La transformación $\varphi : \bar{\Omega} \times \R \rightarrow \Omega \times \R$, dada por
	\begin{equation*}
		\varphi(u, v, \tau) = \left( Ku, \; nKv, \; \dfrac{u\left(u^{2}+\left(\dfrac{a}{K}\right)^{2}\right)}{r} \tau \right) = (x, y, t),
	\end{equation*} define una correspondencia biunívoca y suave entre el sistema \eqref{eq:modelo1} y el \eqref{eq: modelo2}, por lo que $\varphi$ es un difeomorfismo suave, así, $Y_{\eta} = \varphi \circ X_{\mu}$ es topológicamente equivalente al sistema \eqref{eq:modelo1}, donde $Y_{\eta}$ define un sistema polinómico de grado 5.
\end{proof}

\begin{remark}
	Dado que $a$ representa un umbral ecológico inferior a la capacidad de carga $K$ de las presas, se asume $0 < a < K$, lo que implica $0 < A < 1$.
\end{remark}

\begin{remark}
	Desde la perspectiva de la teoría cualitativa, resulta conveniente representar el sistema diferencial autónomo \eqref{eq: modelo2} mediante su campo vectorial asociado $Y_{\eta} = P(u,v) \partial_u + Q(u,v) \partial_v$, donde las componentes del campo están definidas por: 
	\begin{equation*}
		\begin{aligned}
			P(u, v) &= ((1 - u)(u^{2} + A^{2}) - Q u v)u^{2} \; \; \; \text{y} \; \; \;
			Q(u, v) &= B(u - v)(u^{2} + A^{2})v
		\end{aligned}.
	\end{equation*}
	Esta formalización se fundamenta en que si una población se encuentra en la posición $(u,v)$ en un tiempo $\tau$, el sistema \eqref{eq: modelo2} asigna un único vector tangente $(P(u, v), Q(u, v))$, permitiendo así interpretar las soluciones como curvas integrales cuya geometría es dictada por la estructura del operador diferencial $Y_{\eta}$. Otra forma de expresar el campo vectorial es escribiéndolo como $X = (P(u, v), Q(u, v))$.
\end{remark}
\begin{remark}
    El sistema \eqref{eq: modelo2} está definido en $$\tilde{\Omega} = \{ (u, v) \in \R^{2} \; | \; u \geq 0, \; v \geq 0 \}.$$
    Recordemos que el modelo original \eqref{eq:modelo1}, no está definido en el eje $y$ y en particular en $(0,0)$ debido a la forma de la respuesta funcional Leslie-Gower. Al expresar el sistema como un campo polinomial de quinto orden, los autores logran una extensión topológicamente equivalente que sí es válida en el origen. Esto permite estudiar la extinción simultánea de ambas especies, algo que el modelo original impedía analíticamente.
\end{remark}

\begin{lem}
	El conjunto $\Gamma = \{ (u, v) \in \R^{2} \; | \; 0 \leq u \leq 1, \; 0 \leq v \leq 1 \} \subset \tilde{\Omega}$ es una región positivamente invariante.
\end{lem}
\begin{proof}
	Como el sistema \eqref{eq: modelo2} es de tipo Kolmogorov los ejes coordenados son conjuntos invariantes, por lo que basta demostrar que el flujo sobre las fronteras derecha y superior se dirigen hacia el interior de la región. Supongamos que $0 \leq v \leq 1$, reemplazando $u=1$ en la primera ecuación del sistema \eqref{eq: modelo2}, tenemos que: $$\left. \dfrac{du}{d\tau} \right|_{u=1} = -Qv \leq 0,$$ donde, $\dot{u} = 0$, solo si $v=0$. En el punto $(1,0)$, el campo vectorial se reduce a $(0,0)$, esto indica que cualquier trayectoria que comience exactamente aquí, se mantendrá en este punto; y para $v>0$, $\dot{u} = -Qv < 0$ por lo que el flujo sobre la frontera derecha, se dirige hacia la izquierda.
	
	Ahora, para $v=1$, tenemos $\dot{v}=B(u-1)(u^2+A^2)$. Dado que $0\leq u \leq1$, el factor $(u-1)$ es no positivo, lo que implica $\dot{v} \leq0$. Específicamente, $\dot{v} =0$ si y solo si $u=1$. En el punto $(1,1)$, el campo vectorial se reduce a $(-Q,0)$, lo que indica un flujo puramente horizontal hacia la izquierda, manteniendo así el flujo del campo sobre el borde superior o entrando al interior de la región $\Gamma$ en el caso $u<1$. Por lo tanto, el cuadrado unitario $\Gamma$ es una región positivamente invariante.
\end{proof}
\begin{remark}
	Es claro que el conjunto $\Gamma \subset \R^2$ es conexo y cerrado, por lo que $\Gamma$ es una región de atrapamiento. Además, al ser $\Gamma$ un conjunto acotado, da paso al siguiente corolario.
	\label{re:atrapamiento}
\end{remark}
\begin{cor}
	Las soluciones del sistema \eqref{eq: modelo2} son acotadas.
\end{cor}

\end{proof}
Los puntos críticos de \eqref{eq: modelo2} se obtienen resolviendo $g(Y) = 0$, donde $\dot{Y} = g(Y)$ con $Y = (u,v)$, es decir:
\begin{equation}
	\begin{cases}
		((1 - u)(u^{2} + A^{2}) - Q u v)u^{2} = 0\\
		B(u - v)(u^{2} + A^{2})v = 0
	\end{cases}.
\end{equation}
De la primera: $u=0$ o
\begin{equation}
	v = \dfrac{(1-u)(u^2 + A^2)}{Q u} ;
	\label{eq:isoclina-presa_modelo2}
\end{equation}
de la segunda: $v=0$ o $v=u$. Así, $(0,0)$ y $(1,0)$ son equilibrios; el equilibrio $(u_e, v_e)$ surge de la intersección de las isoclinas \eqref{eq:isoclina-presa_modelo2} y $v = u$ \cite{articulo}, esto es equivalente a hallar las raíces del polinomio de grado 3:
\begin{equation}
	P(u) = Qu^{2} - (1-u)(u^2 + A^2) = u^{3} + (Q-1)u^{2} + A^{2}u - A^{2}.
	\label{eq:polinomioIsoclinasModelo2}
\end{equation}
Debido a la naturaleza de nuestro problema, solo son de interés las raíces reales positivas de $P$. Para determinar la cantidad de raíces reales (positivas y negativas), haremos uso de la regla del signo de Decartes \cite{murray2002}[p.~509] y nos apoyaremos en el Teorema fundamental del álgebra.

\begin{pro}
	El polinomio \eqref{eq:polinomioIsoclinasModelo2} tiene una única raíz real positiva.
	\label{pro:exitenciaH}
\end{pro}
\begin{proof}
	Según la naturaleza del coeficiente del segundo termino del polinomio \eqref{eq:polinomioIsoclinasModelo2}, obtenemos los siguientes casos: 
	\begin{itemize}
		\item Si $Q-1 \geq 0, \; P(u)$ tiene 1 cambio de signo, y $$P(-u)=-u^{3}+(Q-1)u^{2}-A^{2}u-A^{2}$$ tiene 2 cambios de signo. Por lo tanto, $P(u)$ tiene una raíz real positiva y dos negativas, o una raíz real positiva y dos complejas.
		\item Si $Q-1<0, \; P(u)$ tiene 3 cambios de signo y $P(-u)$ tiene 0 cambios de signo. Por lo tanto, $P(u)$ tiene tres raíces reales positivas, o una sola raíz real positiva y dos complejas.
	\end{itemize}
	En todo caso, se garantiza la existencia de al menos una raíz real positiva, además, nótese que: $$P(0) = -A^{2}<0 \; \text{ y } \; P(1) = Q>0,$$ así por el teorema del valor intermedio, esta raíz $H \in (0,1)$, esto también se puede deducir de la isoclina \eqref{eq:isoclina-presa_modelo2}. Descartemos ahora la posible existencia de tres raíces reales positivas simultáneamente; para ello observemos que el cociente entre $P(u)$ y el monomio $u - H$ es $$P_{1}(u) = u^{2}+(Q-1+H)u+(Q-1+H)H+A^{2}$$ con resto $$R(u) = H^{3}+(Q-1)H^{2}+A^{2}H-A^{2} = 0,$$ de aquí $$Q-1+H = \frac{(1-H)A^{2}}{H^{2}}>0$$ reemplazando en $P_{1}(u)$ obtenemos $$P_{1}(u) = u^{2}+\frac{(1-H)A^{2}}{H^{2}}u+\frac{A^{2}}{H},$$ así nuevamente por la regla de los signos de Descartes, concluímos que $P_{1}$ no tiene raíces reales positivas, logrando con ello determinar que el polinomio \eqref{eq:polinomioIsoclinasModelo2} consta de una única raíz real positiva.
\end{proof}

\begin{remark}
	Con esta ultima proposición se concluye que el sistema \eqref{eq: modelo2} posee tres puntos de equilibrio biológicamente relevantes: $(0,0), \; (1,0) \text{ y } (H,H),$ donde, $H \in (0,1)$.
\end{remark}

\begin{equation*}
	Dg(Y) =
	\begin{bmatrix}
			-5u^{4} + 4u^{3} - (3A^{2} + 3Qv)u^{2} + 2A^{2}u & -Qu^{3} \\
			3Bu^{2}v+BvA^{2}-2Bv^{2}u & B(u^{2}+A^{2})(u-2v)

	\label{eq:jacobianaModelo2}
\end{equation*}

\subsection{Estabilidad del punto de equilibrio $(1,0)$}
En $(1,0)$:
\begin{equation*}
	Dg(1,0) =
	\begin{bmatrix}
		-(1+A^{2}) & -Q \\
		0 & B(1+A^{2})
	\end{bmatrix}.
	\label{eq:jacobianaModelo2En(1,0)}
\end{equation*}
Los valores propios son $\lambda_1 = -(1+A^{2}) < 0$ y $\lambda_2 = B(1+A^{2}) > 0$. Dado que tienen signos opuestos, $(1,0)$ es un punto silla.

\subsection{Estabilidad del punto de equilibrio $(0,0)$}
En $(0,0)$:
\begin{equation*}
	Dg(0,0) =
	\begin{bmatrix}
		0 & 0 \\
		0 & 0
	\end{bmatrix}.
	\label{eq:jacobianaModelo2En(0,0)}
\end{equation*}
En particular, para este punto de equilibrio al obtener la matriz nula, deducimos que el punto crítico $(0,0)$ es un punto no hiperbólico y degenerado, por lo que no es posible determinar la estabilidad de este punto por medio de la linealización ni el teorema de la variedad central, por ello, para analizar el comportamiento de este punto de equilibrio se recurrirá a desingularizarlo a través del método de blowing-up polar.

Para ello, escribamos el sistema \eqref{eq: modelo2} en coordenadas polares. Sustituyendo $u = r \cos\theta$ y $v = r \sin\theta$, obtenemos que $r^{2}=u^{2}+v^{2} \;\text{ y }\; \theta = \arctg\left(\dfrac{v}{u}\right)$ con $u\neq0$. Derivando con respecto al tiempo $\tau$: $$\dot{r}=\cos\theta\dot{u} + \sin\theta\dot{v} \;\text{ y }\; \dot{\theta}=\dfrac{\dot{v}\cos\theta-\dot{u}\sin\theta}{r}.$$ Reemplazando $\dot{u}$ y $\dot{v}$ obtenemos el sistema:
\begin{equation*}
	\begin{cases}
		\dot{r} &= r^{2} f(r, \theta)
		\\
		\dot{\theta} &= r g(r, \theta)
	\end{cases},
\end{equation*}
donde
\begin{equation*}
	\begin{aligned}
		f(r, \theta) &= -Qr^{2}\cos^{4}\theta\sin\theta- r^{3}\cos^{6}\theta+ r^{2}\cos^{5}\theta \\ &-A^{2}r\cos^{4}\theta+ A^{2}\cos^{3}\theta + Br^{2}\cos^{3}\theta\sin^{2}\theta \\ &-Br^{2}\cos^{2}\theta\sin^{3}\theta+ A^{2}B\cos\theta\sin^{2}\theta- A^{2}B\sin^{3}\theta
		\\
		g(r, \theta) &= Br^{2}\cos^{4}\theta\sin\theta- Br^{2}\cos^{3}\theta\sin^{2}\theta+ A^{2}B\cos^{2}\theta\sin\theta \\ &-A^{2}B\cos\theta\sin^{2}\theta+ Qr^{2}\cos^{3}\theta\sin^{2}\theta + r^{3}\cos^{5}\theta\sin\theta \\ &-r^{2}\cos^{4}\theta\sin\theta+ A^{2}r\cos^{3}\theta\sin\theta- A^{2}\cos^{2}\theta\sin\theta
	\end{aligned},
\end{equation*}
es decir, obtuvimos el campo vectorial $$\tilde{Y_{\eta}}(r,\theta) = r^{2}f(r,\theta) \partial_r + rg(r,\theta) \partial_\theta.$$ Dividiendo por $r$ obtenemos un nuevo campo $$\bar{Y_{\eta}}(r,\theta) = rf(r,\theta) \partial_r + g(r,\theta) \partial_\theta,$$ el cual, en $\{r=0\}$ es cualitativamente equivalente a una vecindad $V$ del origen del campo vectorial $Y_{\eta}$ dado por el sistema \eqref{eq: modelo2}, es decir, basta analizar el retrato fase del campo vectorial:
\begin{equation*}
	\begin{aligned}
		\bar{Y_{\eta}}(0,\theta) = g(0, \theta) &= A^{2}B\cos^{2}\theta\sin\theta - A^{2}B\cos\theta\sin^{2}\theta- A^{2}\cos^{2}\theta\sin\theta \\
		&= A^{2}\cos\theta\sin\theta (B\cos\theta-B\sin\theta-\cos\theta),
	\end{aligned}
\end{equation*}
para determinar el comportamiento del sistema \eqref{eq: modelo2} en una vecindad del origen.

Hallemos los puntos críticos de $\bar{Y_{\eta}}(0,\theta)$ ubicados en el primer cuadrante. Igualando el campo vectorial $\bar{Y_{\eta}}(0,\theta)$ a cero, debe ocurrir al menos que $\cos\theta$, $\sin\theta$ o $B\cos\theta-B\sin\theta-\cos\theta$ se anule. Esto ocurre para los valores $\theta_1 = 0, \; \theta_2 = \dfrac{\pi}{2}$ y los que cumplan la igualdad $$\dfrac{B-1}{B}\cos\theta=\sin\theta,$$ es decir, $\theta_3 = \arctg\left( \dfrac{B-1}{B} \right)$; aquí, notemos que el escenario de relevancia es para el caso $B>1$, pues para $B=1$ estaríamos hablando de $\theta_3 = \theta_1 = 0$ y para $B<1$, $\theta_3$ no estaría en el primer cuadrante.

Ahora, dada la matriz jacobiana:
\begin{equation*}
	D\bar{Y_{\eta}}(0,\theta) =
	\begin{bmatrix}
		h_{1}(\theta)  & 0\\
		A^{2}\cos^{3}\theta\sin\theta & h_{2}(\theta)
	\end{bmatrix},
	\label{eq:jacobianaModelo2Polar}
\end{equation*}
con
\begin{equation*}
	\begin{aligned}
		h_{1}(\theta) &= A^{2}\cos^{3}\theta + A^{2}B[\cos\theta\sin^{2}\theta - \sin^{3}\theta] \\
		h_{2}(\theta) &= A^{2}B[\sin^{3}\theta + \cos^{3}\theta - 2\sin^{2}\theta\cos\theta - 2\sin\theta\cos^{2}\theta] \\
		& + A^{2}[2\cos\theta\sin^{2}\theta - \cos^{3}\theta].
	\end{aligned}
\end{equation*}

\subsubsection*{Estabilidad en $(0, \theta_1)$}
En el punto crítico $(0,0)$, obtenemos la matriz:
\begin{equation*}
	D\bar{Y_{\eta}}(0,0) =
	\begin{bmatrix}
		A^{2}  & 0 \\
		0 & A^{2}(B-1)
	\end{bmatrix},
	\label{eq:jacobianaModelo2PolarEn(0,0)}
\end{equation*}
con valores propios $\lambda_r = A^{2}>0$ y $\lambda_\theta = A^{2}(B-1)$. Por lo tanto, $(0, \theta_1)$ es un punto silla de $\bar{Y_{\eta}}(0,\theta)$ si $B<1$, es una fuente si $B>1$ y un punto crítico no hiperbólico si $B=1$. Aquí observamos qué la estabilidad de este punto de equilibrio depende del parámetro $B$, la cual influirá en la estructura cualitativa del campo $\bar{Y_{\eta}}(r,\theta)$ y por ende en la del sistema \eqref{eq: modelo2}. % Así, obtenemos que hay un cambio cualitativo en el valor de bifurcación $B=1$, posteriormente se analizará que tipo de bifurcación se presenta en este modelo.

Ahora, debido a que en el caso $B=1$ el punto $(0,\theta_1)$ es un punto no hiperbólico, no es posible aplicar el teorema de Harmant-Grobman para determinar su estabilidad y por ello recurriremos al teorema de la variedad central.

Recordemos que este último nos garantiza la existencia de una curva invariante $r = h(\theta)$ que define la variedad central en una vecindad del origen, cuyo flujo esta determinado por la ecuación diferencial $\dot{\theta} = g(h(\theta), \theta)$. En nuestro caso, al estar determinando la estabilidad de los puntos críticos en el circulo ${r = 0}$, esto conlleva a la omisión de tener que especificar como esta definida la curva invariante $h(\theta)$. Por ende, para precisar la estabilidad del origen para el caso $B = 1$, solo basta determinar el flujo de la ecuación diferencial $\dot{\theta} = g(0, \theta) = - A^2 \sin ^2 \theta \cos \theta$; para ello, hallemos los primeros términos de la expansión en serie de Taylor de $-A^2 \sin ^2 \theta \cos \theta$ alrededor de $\theta = 0$. Como

\begin{equation*}
	\begin{aligned}
		\sin \theta &= \theta - \dfrac{\theta^3}{3!} + \mathcal{O}(\theta^ 5) \\
		\sin^2 \theta &= \theta^2 + \mathcal{O}(\theta^ 4) \\
		\cos \theta &= 1 - \dfrac{\theta^2}{2!} + \mathcal{O}(\theta^ 4)
	\end{aligned},
\end{equation*}
tenemos que
\begin{equation*}
	\dot{\theta} = - A^2 \sin ^2 \theta \cos \theta = -A^2 \theta^2 + \mathcal{O}(\theta^ 4).
\end{equation*}
Así, como el orden del primer termino de la expansión es par, se concluye que $(0, \theta_1)$ para el caso $B=1$ es un punto silla-nodo de $\bar{Y_{\eta}}(0,\theta)$ \cite{perko2001}[p.~157].

\subsubsection*{Estabilidad en $(0, \theta_2)$}

Tenemos que:
\begin{equation*}
	D\bar{Y_{\eta}}\left(0,\dfrac{\pi}{2}\right) =
	\begin{bmatrix}
			-A^{2}B  & 0 \\
			0 & A^{2}B
		\end{bmatrix},
	\label{eq:jacobianaModelo2PolarEn(0,pi2)}
\end{equation*}
con valores propios $\lambda_r = -A^{2}B<0$ y $\lambda_\theta = A^{2}B>0$. Por lo tanto, $\left(0,\theta_2\right)$ es un punto silla de $\bar{Y_{\eta}}(0,\theta)$.

\subsubsection*{Estabilidad en $(0, \theta_3)$}

Ahora, denotando $b = \left( \dfrac{B-1}{B} \right)$, donde $B>1$, y tomando en cuenta las identidades
\begin{equation*}
	\begin{aligned}
		\sin(\arctg(b)) &= \dfrac{b}{\sqrt{1+b^{2}}} \\
		\cos(\arctg(b)) &= \dfrac{1}{\sqrt{1+b^{2}}}
	\end{aligned},
\end{equation*}
llegamos a que
\begin{equation*}
	D\bar{Y_{\eta}}\left(0,\arctg(b)\right) = \dfrac{A^{2}}{(1+b^{2})^{3/2}}
	\begin{bmatrix}
		a_{11} & 0 \\
		\dfrac{b}{(1+b^{2})^{1/2}} & a_{22}
	\end{bmatrix},
\end{equation*}
donde
\begin{equation*}
	\begin{aligned}
		a_{11} &= 1 + Bb^{2}(1-b) \\
		a_{22} &= B(b^{3}-2b+1) -2b^{2}(B-1) - 1
	\end{aligned}
\end{equation*}
reemplazando $b = \left( \dfrac{B-1}{B} \right)$, obtenemos que:
\begin{equation*}
	\begin{aligned}
		a_{11} &= 1 + B\dfrac{(B-1)^{2}}{B^{2}}\left(1-\dfrac{B-1}{B}\right) \\ 
		&=\dfrac{2B^{2}-2B+1}{B^{2}} \\
		a_{22} &= B\left(\dfrac{(B-1)^{3}}{B^{3}}-2\dfrac{B-1}{B}+1\right) -2\dfrac{(B-1)^{2}}{B^{2}}(B-1) - 1 \\ 
		&= 1 - B - \dfrac{(B-1)^{3}}{B^{2}} \\
		1+b^{2} &= \dfrac{2B^{2}-2B+1}{B^{2}}
	\end{aligned}
\end{equation*}
Así,
\begin{equation*}
	D\bar{Y_{\eta}}\left(0,\arctg(b)\right) = \alpha
	\begin{bmatrix}
		\dfrac{2B^{2}-2B+1}{B^2} & 0 \\
		\dfrac{(B-1)B}{(2B^{2}-2B+1)^{1/2}} & -\dfrac{(B-1)(2B^{2}-2B+1)}{B}
	\end{bmatrix},
	\label{eq:jacobianaModelo2PolarEn(0,b)}
\end{equation*}
donde $\alpha = \dfrac{A^{2}B^{3}}{(2B^{2}-2B+1)^{3/2}}>0$. Con valores propios $$\lambda_r =\alpha \dfrac{2B^{2}-2B+1}{B^{2}}>0 \; \text{y} \; \lambda_\theta  = -\alpha \dfrac{(B-1)(2B^{2}-2B+1)}{B}<0.$$ Por lo tanto, $(0,\theta_3)$ es un punto silla.

	\includegraphics[width=.7\textwidth]{img/blowingUpPolar.pdf}
	\caption{Blow-up en el origen del sistema \eqref{eq: modelo2} para el caso $B>1$.}
	\label{fig: BlowUp Modelo 2}
\end{figure}

Luego de hallar la estabilidad de cada punto crítico de $\bar{Y_{\eta}}$, junto con sus respectivos valores propios radiales y tangenciales, podemos determinar como se comporta cualitativamente el origen del campo $Y_{\eta}$ en una cierta vecindad. Este comportamiento se puede evidenciar en la figura \ref{fig: BlowUp Modelo 2}, en donde, para el caso $B\leq1$ vemos que el primer cuadrante consta de un único sector hiperbólico, y para $B>1$ de uno parabólico y uno hiperbólico. Recordemos que la finalidad de la técnica del blow-up es determinar el comportamiento del origen en $Y_{\eta}$, en sí, este proceso nos permite determinar que trayectorias entran o salen del origen, y son determinadas por la pendiente $\tan \theta^*$, donde $\theta^*$ es un punto crítico de $\bar{Y_{\eta}}$. Por ende, en el primer cuadrante de $Y_{\eta}$ hay tres de estas trayectorias: $v=0$ que corresponde a la orbita con pendiente $\tan\theta_1=0$, $u=0$ que corresponde a la orbita con pendiente $\tan\theta_2= \infty$ y la orbita determinada por la pendiente $\tan\theta_3=\dfrac{B-1}{B}$, la cual, esta última solo se da para el caso $B>1$, y además define una curva separatriz puesto que divide el retrato de fase en dos sectores con comportamientos cualitativos distintos (parabólico e hiperbólico).

\subsection{Estabilidad del punto de equilibrio $(H,H)$}
Con el fin de reducir los posibles casos que se pueden dar en los valores propios, reduciremos la cantidad de parámetros realizando la sustitución
\begin{equation}
	Q=\dfrac{(1-H)(A^2+H^{2})}{H^{2}},
	\label{eq: Q}
\end{equation}
anteriormente discutida en la \Cref{pro:exitenciaH}. Así, tendríamos que en $(H,H)$:
\begin{equation*}
	Dg(H,H) =
	\begin{bmatrix}
		-H(H^{2}(2H-1)+A^2) & -H(1-H)(A^2+H^2) \\
		BH(A^{2}+H^{2}) & -BH(A^{2}+H^{2})
	\end{bmatrix}.
	\label{eq:jacobianaModelo2En(H,H)}
\end{equation*}
Los valores propios se hallan del polinomio característico $\lambda^2 - \operatorname{tr}(A) \lambda + \det(A) = 0$, con $A = Dg(H,H)$, estos es:
\begin{equation*}
	\lambda = \dfrac{\operatorname{tr}(A) \pm \sqrt{\Delta}}{2},
\end{equation*}
donde, $\Delta = (\operatorname{tr}(A))^2 - 4\det(A)$ y
\begin{equation*}
	\begin{aligned}
		\operatorname{tr}(A) &= -H(B(A^{2}+H^{2})+H^{2}(2H-1)+A^2) \\
		\det(A) &= BH^2(A^2+H^2)(H^3+A^2(2-H))
	\end{aligned}.
\end{equation*}
Como $H \in (0, 1)$, $\det(A)>0$ por lo que $(H,H)$ es un punto no degenerado e hiperbólico o punto centro; además, no puede ser un punto silla. Así la estabilidad estaría determinada por el signo de la traza y del discriminante $\Delta$, para ello notemos que $\operatorname{tr}(A)=0$ si $B=(H^2(1-2H) - A^2)/(A^2 + H^2):=B_c$, y puesto que $B>0$, esto se da bajo las restricciones: $H<1/2$ y $A^2 < H^2(1-2H)$. Este hecho da paso a los siguientes casos:
\begin{itemize}
	\item Si $B<B_c$ y
	\subitem $\Delta < 0$, $(H,H)$ es un foco inestable.
	\subitem $\Delta = 0$, $(H,H)$ es un nodo degenerado inestable.
	\subitem $\Delta > 0$, $(H,H)$ es un nodo inestable.
	\item Si $B=B_c$, $(H,H)$ es un centro lineal.
	\item Si $B>B_c$ y
	\subitem $\Delta < 0$, $(H,H)$ es un foco estable.
	\subitem $\Delta = 0$, $(H,H)$ es un nodo degenerado estable.
	\subitem $\Delta > 0$, $(H,H)$ es un nodo estable.
\end{itemize}

Dado que la linealización no garantiza que $(H, H)$ sea un punto centro para el caso $B=B_c$, ya que en este caso el punto de equilibrio es no hiperbólico, se es de importancia verificar si $(H, H)$ es un punto centro o un foco débil en el sistema no linealizado. Con el propósito de validar la estructura cualitativa en este caso, calcularemos el número de Lyapunov; esto no es sólo con este fin, sino con el de validar que tipo de bifurcación de Hopf se nos presenta, puesto que dicha característica esta garantizada debido a la región de atrapamiento $\Gamma$ descrita en la \Cref{re:atrapamiento}, y del hecho de que $(H,H)$ es un repulsor para el caso $B<B_c$, existe un ciclo límite según el Teorema de Poincaré-Bendixson.

\subsubsection{Calculo del coeficiente de Lyapunov}
Para proceder con el calculo del primer coeficiente de Lyapunov, debemos trasladar el punto de equilibrio $(H, H)$ al origen. Para ello, realicemos las sustituciones $u = \bar{u} + H$ y $v = \bar{v} + H$ en el sistema \eqref{eq: modelo2}; pero, antes de ello realizamos la sustitución \eqref{eq: Q} con el fin de reducir la cantidad de parámetros. Estos cambios se ven reflejados de la siguiente manera:

\begin{equation}
	W_{\eta}:
	\begin{cases}
		\dfrac{d\bar{u}}{d \tau} = (H+\bar{u})^2 \left((-H-\bar{u}+1) (A^2+(H+\bar{u})^2) - \frac{(1-H) (A^2+H^2)}{H^2} (H+\bar{u}) (H+\bar{v})\right) \\
		\dfrac{d\bar{v}}{d \tau} = B (H+\bar{v}) (\bar{u}-\bar{v}) \left(A^2+(H+\bar{u})^2\right)
	\end{cases},
	\label{eq: modelo2Hen0}
\end{equation}
